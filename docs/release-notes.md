## Grim Dawn — Party Teleport 0.3.0 (experimental)

- **F8 is the only hotkey:** press it to enter settings, then press it again to return to teleport buttons only.
- The settings panel includes English/Russian language buttons, row-spacing controls, **Done (F8)** and **Exit app**.
- Drag the settings header or a placeholder row to move the entire button column.
- Teleport requests cannot be issued during settings mode. Holding F8 does not repeatedly toggle it.
- Removed the F9, F10, F11 and F12 shortcuts.
- Updated both READMEs and the rendered UI preview; added hidden-window UI interaction tests.

Start Grim Dawn x64 through Steam, then use **Grim Dawn — Party Teleport**. Use windowed or borderless mode. Close both the app and game before updating.

**Experimental:** live multiplayer teleportation, host/client synchronization and compatibility with other injected mods remain unverified. F8 may conflict with another mod's binding. Supported DLL hashes and approximate distance assumptions are described in the README.

### Русский

Теперь используется только **F8**: первое нажатие открывает настройку, повторное оставляет только кнопки телепортации. В панели можно выбрать English/Русский, изменить шаг строк, перетащить весь блок за заголовок и закрыть приложение. Есть кнопка **Готово (F8)**. В настройке телепортация отключена. Прежние F9–F12 удалены.

Обновлены оба README и пример интерфейса, добавлены тесты взаимодействия со скрытыми окнами. Перед обновлением закройте игру и приложение. Проверка в живой сетевой группе ещё требуется.
