## Grim Dawn — Party Teleport 0.2.0 (experimental)

- English is now the default; Russian remains available in Setup, Start menu shortcuts and with F12.
- Desktop and Start menu branding: **Grim Dawn — Party Teleport**.
- Original dark bronze buttons with green rift icons and hover feedback.
- Approximate straight-line distance for teammates in the same loaded region.
- English primary README and Russian translation.
- Windows build, tests, installer, portable ZIP and SHA-256 checksums through GitHub Actions.

Start Grim Dawn x64 through Steam, then use **Grim Dawn — Party Teleport**. Use windowed or borderless mode. Close both the app and game before upgrading from 0.1.

**Experimental:** live multiplayer teleportation, host/client synchronization and compatibility with other injected mods have not been verified. Supported DLL hashes and limitations are in the README. Distances assume one world unit is approximately one metre; the scale is not yet calibrated.

### Русский

Английский теперь основной; русский доступен в установщике, отдельных ярлыках и через F12. Ярлык называется **Grim Dawn — Party Teleport**. Добавлены бронзовое оформление, приблизительные расстояния в одной области, два README и сборка установщика/ZIP в GitHub Actions.

Сначала запустите Grim Dawn x64 через Steam, затем ярлык мода. Нужен оконный режим или окно без рамки. Перед обновлением с 0.1 закройте игру и приложение. Работа в живой группе пока требует проверки.
